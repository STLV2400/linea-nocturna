# LÍNEA NOCTURNA — Hotel Miraflores

Juego de terror en 3D para navegador: eres el recepcionista del turno de noche y debes distinguir las llamadas de huéspedes reales de las de los fantasmas del incendio de 1987.

- **Jugar:** `JUGAR.html`
- **Personajes:** `personajes.html`
- **Recorrer la recepción:** `escenario.html`

Créditos de recursos: modelos y texturas de [Poly Haven](https://polyhaven.com) (CC0) · personajes base de [Microsoft Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox) (MIT) · motor [three.js](https://threejs.org) (MIT).
